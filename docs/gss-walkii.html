Step 1

Step 1｜攔截 App 請求

工具清單
工具：Quantmult X
功能：手機流量中間人分析（MitM）
平台：iOS
輸出物：HAR 檔案
操作步驟
1
安裝並信任 MitM 根證書
2
開啟 VPN + HTTP 數據抓取
3
操作 Walkii App，觸發 API 請求
輸出物 → HAR 檔案，作為後續 API 驗證與前端串接的基礎。

4
Step 2

Step 2｜驗證 API 可用性

Postman 方式
  • HAR → Chrome Network
  • 複製 curl → 匯入 Postman Collection
  • 測試 API 回傳結果
Requable 方式
  • HAR 直接拖入 Requable
  • 一步完成導入
  • 測試 API 回傳結果
⚠ 確認 API 正常回傳資料後，才進入前端開發。

Step 3｜選擇前端技術棧

Shadcn 選擇理由
✔ 開源 MIT 授權，允許商用
✔ 官方 CLI，快速建立應用
✔ AI Skill / MCP 整合，提高生成效率
部署平台：Vercel
優勢是 GitHub 推送即自動部署，不需自行維運伺服器，適合快速驗證與對外發布。
